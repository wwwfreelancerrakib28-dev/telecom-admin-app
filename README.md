# SIM OFFER SHOP ADMIN PANEL

React + Vite + Tailwind CSS + Capacitor Android admin panel.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Android

The GitHub Actions workflow automatically creates the Capacitor Android platform and builds a debug APK.

Push the project to a GitHub repository on the `main` branch, or manually run the workflow from the Actions tab.
